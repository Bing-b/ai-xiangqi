📖 游戏操作与玩法说明

🎯 基础行棋操作

  • 选择棋子：点击己方棋子，棋子将呈现高亮选中状态。
  • 走棋/吃子：点击棋盘上的绿色高亮圈（可行走目标）或红色目标圈（可吃目标）即可落子。

⚔️ 对战模式介绍

  • 👥 双人对决 (PvP)：支持同屏两人轮流执红/执黑下棋。
  • 🤖 人机对弈 (PvAI)：与 AI 进行对决。可自定义玩家执红（先手）或执黑（后手）。
  • 🏆 残局闯关 (Endgame)：内置《双马饮泉》、《千里独行》等经典杀局，破解通关后会自动保存记录。

🤖 GPT 大模型 AI 对弈

  • 在 AI 难度中选择 ✨ GPT 大模型对弈 模式。
  • 在 js/config.js 中填写您的 Key 与中转 Base URL。
  • GPT 下棋时会在侧边栏输出**实时的战术思路与棋局点评**！

🛠️ 实用工具与快捷按键

  • ↩️ 悔棋：撤销上一步走法（人机模式下自动连撤两步）。
  • 💡 提示：AI 自动计算并显示当前局势的最优走法。
  • 📜 FEN/棋谱：支持复制/加载 FEN 局面状态或导出 PGN 文本棋谱。
  • 🎨 棋盘主题：可切换【经典木纹】、【典典水墨】、【赛博暗黑】皮肤。

🔑 GPT API 安全设置

🛡️ 安全防泄漏提示：您的 API Key 将仅保存在您浏览器的本地存储 (localStorage) 中，绝不会写入源代码文件或上传至任何远程仓库。
